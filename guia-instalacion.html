Requisitos

Antes de empezar

Revise esta lista. Si cumple todo, puede continuar sin problema:

  • Computadora con Windows 10 (versión reciente) o Windows 11, de 64 bits.
  • Espacio libre: al menos 10 GB libres en el disco C: (Visual Studio ocupa varios gigabytes).
  • Internet estable: el instalador descarga los componentes mientras instala. Si puede, instale con buena señal o en el centro de cómputo.
  • Permisos de administrador: Windows pedirá permiso. Si es una computadora prestada, pida ayuda al propietario.
  • Tiempo: reserve entre 30 y 60 minutos para Visual Studio (según su Internet) y 5 minutos para DB Browser.
Parte 1

Instalar Visual Studio Community 2026

Visual Studio es un programa completo (IDE) para programar. Es gratuito en su edición Community para estudiantes. Como nuestro componente es de aplicaciones de escritorio, solo necesitamos instalar la parte de Windows Forms.

Paso 1. Descargar el instalador

  1. Abra su navegador y entre a visualstudio.microsoft.com/downloads.
  2. Busque la edición Community (la gratuita) y haga clic en «Descarga gratuita» (Free download).
  3. Espere a que se descargue el archivo (normalmente vs_community.exe). Quedará en su carpeta Descargas.

Paso 2. Abrir el instalador

  1. Haga doble clic en el archivo descargado.
  2. Si Windows pregunta «¿Desea permitir que esta aplicación realice cambios?», elija Sí.
  3. En la ventana de bienvenida, pulse Continuar.

Paso 3. Elegir SOLO lo que necesitamos (muy importante)

Aparecen muchas «cargas de trabajo». Visual Studio sirve para web, videojuegos, móvil y más, pero aquí no necesitamos todo eso: mientras más marque, más tarda la instalación y más espacio ocupa.

✔ Marque únicamente
«Desarrollo de escritorio de .NET» (.NET desktop development). Incluye todo lo necesario para crear aplicaciones Windows Forms con C#.
✘ No marque ninguna otra
Ni desarrollo web (ASP.NET), Azure, C++, Python, Node.js, Plataforma universal de Windows, juegos ni móvil. Si alguna aparece marcada por defecto, quítele el check.
  1. En la pestaña «Cargas de trabajo», ubique la sección «Escritorio y móvil» (Desktop & Mobile).
  2. Haga clic en la tarjeta «Desarrollo de escritorio de .NET» para marcarla (verá un check azul ✔).
  3. Revise que ninguna otra tarjeta tenga el check.
  4. A la derecha, en «Detalles de la instalación», no cambie nada.

Paso 4. (Opcional) Elegir el idioma

  1. Vaya a la pestaña «Paquetes de idioma» (Language packs).
  2. Si prefiere los menús en español, marque Español. Deje también English marcado: la mayoría de tutoriales y errores aparecen en inglés.

Paso 5. Instalar y esperar

  1. Revise que abajo a la derecha diga el botón Instalar y haga clic en él.
  2. Espere a que termine la descarga e instalación. Puede tardar entre 15 y 60 minutos.
  3. No apague ni suspenda la computadora ni cierre la ventana mientras avanza la barra.

Paso 6. Iniciar sesión

  1. Al terminar, Visual Studio puede abrirse solo. Si no, búsquelo en el menú Inicio: «Visual Studio 2026».
  2. Le pedirá iniciar sesión con una cuenta Microsoft (Outlook, Hotmail o la de su institución). Es recomendable hacerlo para mantener activa la licencia gratuita Community.
  3. Si todavía no tiene cuenta, puede elegir «Omitir y agregar cuentas más tarde», pero deberá iniciar sesión dentro del plazo que indique el programa.

Paso 7. Comprobar que Windows Forms funciona

  1. En la pantalla de inicio, haga clic en «Crear un proyecto nuevo» (Create a new project).
  2. En el cuadro de búsqueda escriba winforms.
  3. Elija «Aplicación de Windows Forms» (Windows Forms App) con el lenguaje C#. No elija la que dice «.NET Framework».
  4. Pulse Siguiente, póngale el nombre PruebaInstalacion, pulse Siguiente otra vez y luego Crear (deje el .NET que le proponga).
  5. Cuando se abra el diseñador con una ventana vacía, presione F5 (o el botón verde ▶ «Iniciar»). Debe aparecer una ventana en blanco: ¡funciona!
¿No aparece la plantilla Windows Forms? No se instaló la carga correcta. Abra «Visual Studio Installer» desde el menú Inicio, pulse «Modificar» en Visual Studio Community 2026, marque «Desarrollo de escritorio de .NET» y pulse «Modificar» otra vez.
Parte 2

Instalar DB Browser for SQLite

DB Browser for SQLite (DB4S) es un programa gratuito y ligero para crear, abrir y consultar bases de datos SQLite de forma visual. Lo usaremos para ver las tablas y los datos que guardan nuestras aplicaciones.

Paso 1. Descargar el instalador

  1. Entre a sqlitebrowser.org/dl.
  2. En la sección Windows, haga clic en «DB Browser for SQLite - Standard installer for 64-bit Windows».
  3. Si su computadora es muy antigua (32 bits), elija la opción «32-bit».
  4. Se descargará un archivo .msi (con un nombre parecido a DB.Browser.for.SQLite-v3.13.1-win64.msi).

Paso 2. Ejecutar el instalador

  1. Haga doble clic en el archivo .msi descargado.
  2. En la primera pantalla pulse Next / Siguiente.
  3. Marque la casilla «I accept the terms in the License Agreement» (Acepto los términos) y pulse Next.

Paso 3. Accesos directos

  1. Deje marcados Desktop (Escritorio) y Program Menu (Menú Programas). Así podrá abrirlo fácilmente.
  2. Pulse Next.

Paso 4. Instalar

  1. Pulse Install. Si Windows pregunta si permite cambios, elija Sí.
  2. Espere unos segundos y pulse Finish (Finalizar).

Paso 5. Abrir el programa y comprobar

  1. Abra DB Browser for SQLite desde el acceso directo del Escritorio o desde el menú Inicio.
  2. Debe ver la ventana con las pestañas «Estructura de la base de datos», «Hoja de datos» y «Ejecutar SQL». Si la ve, quedó instalado correctamente.

Problemas frecuentes

ProblemaQué hacer
El instalador se queda detenido o falla la descargaRevise su Internet, cierre y vuelva a abrir el instalador; continúa donde se quedó. Evite instalar con datos móviles inestables.
Dice que no hay espacio en discoLibere espacio en el disco C: (al menos 10 GB) borrando archivos temporales o programas que ya no use.
No encuentro «Windows Forms» al crear el proyectoAbra Visual Studio Installer → Modificar → marque «Desarrollo de escritorio de .NET».
Windows muestra una advertencia al abrir el instaladorVerifique que lo descargó desde las páginas oficiales de esta guía y elija «Sí» o «Ejecutar de todos modos».

Si se queda atascado, tome una captura de pantalla del mensaje y llévela al encuentro o envíela al grupo de WhatsApp.
