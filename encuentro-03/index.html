Vivencia

La cooperativa a la que pertenece el agroservicio de doña Martha pide cada lunes un reporte de inventario en PDF y el valor total en dólares con el tipo de cambio del día. Su hijo copia a mano la tabla en Excel y busca el tipo de cambio en el celular; si la señal es mala, el reporte se atrasa.

  1. ¿Qué partes de este proceso podría automatizar AgroStock?
  2. En AgroStock v2 escribiste muchas sentencias SQL parecidas. ¿Qué pasaría si mañana hubiera que cambiar a SQL Server?
  3. ¿Qué debería hacer la aplicación cuando no hay Internet?
  4. ¿Cuánto papel y cuántos viajes se ahorran si el reporte se envía en digital?
Lo que esperamos aprender: manipular la base de datos con objetos (ORM), producir reportes profesionales y conectar la aplicación con servicios en Internet de forma robusta.

Unidad IV · 1. ¿Qué es un ORM?

Un ORM (Object-Relational Mapper, mapeador objeto-relacional) traduce automáticamente entre los objetos del programa y las tablas de la base de datos. El programador trabaja con clases y colecciones; el ORM genera el SQL, abre las conexiones y convierte las filas en objetos. En .NET, el ORM oficial es Entity Framework Core (EF Core).

Mundo orientado a objetosMundo relacional
Clase ProductoTabla Productos
Propiedad NombreColumna Nombre
Objeto (instancia)Fila
Referencia Producto.CategoriaClave foránea CategoriaId
List<Producto> Categoria.ProductosRelación 1:N
  • Ventajas: menos código repetitivo, consultas verificadas por el compilador (LINQ), independencia del motor (SQLite, SQL Server, MySQL, PostgreSQL), protección contra inyección SQL.
  • Límites: menos control sobre el SQL generado; consultas muy complejas pueden ser menos eficientes; hay que entender qué consulta se ejecuta y cuándo.
Unidad IV · 2. Entity Framework Core: entidades y DbContext
C#
public class Producto
{
    public int Id { get; set; }                         // clave primaria por convención
    [Required, MaxLength(10)] public string Codigo { get; set; } = "";
    public int CategoriaId { get; set; }                // clave foránea
    public Categoria? Categoria { get; set; }           // propiedad de navegación
    public decimal Precio { get; set; }
    public int Existencia { get; set; }
}

public class AgroStockContext : DbContext
{
    public DbSet<Producto> Productos => Set<Producto>();
    public DbSet<Categoria> Categorias => Set<Categoria>();

    protected override void OnConfiguring(DbContextOptionsBuilder o) =>
        o.UseSqlite("Data Source=agrostock_ef.db");

    protected override void OnModelCreating(ModelBuilder mb)
    {
        mb.Entity<Producto>().HasIndex(p => p.Codigo).IsUnique();
        mb.Entity<Categoria>().HasData(new Categoria { Id = 1, Nombre = "Fertilizantes" });
    }
}

El DbContext representa una sesión de trabajo con la base: rastrea los objetos que se agregan o modifican y, al llamar a SaveChanges(), genera y ejecuta los INSERT, UPDATE y DELETE necesarios dentro de una transacción. Database.EnsureCreated() crea la base y las tablas si no existen; en proyectos mayores se usan migraciones (dotnet ef migrations add).

Unidad IV · 4. Generación de reportes

Un reporte presenta datos de la base de forma organizada para tomar decisiones. Su estructura clásica: encabezado (título, fecha, filtros), detalle (filas), agrupaciones y totales, y pie (numeración). El programa pide exportar a PDF o Excel; usamos dos bibliotecas libres para uso académico: QuestPDF (PDF con API fluida en C#) y ClosedXML (Excel sin necesidad de tener Office instalado).

C#
Document.Create(doc => doc.Page(page =>
{
    page.Size(PageSizes.Letter);
    page.Margin(2, Unit.Centimetre);
    page.Header().Text("AgroStock – Reporte de inventario").SemiBold().FontSize(16);
    page.Content().Table(t =>
    {
        t.ColumnsDefinition(c => { c.ConstantColumn(60); c.RelativeColumn(); c.ConstantColumn(80); });
        t.Header(h => { h.Cell().Text("Código"); h.Cell().Text("Producto"); h.Cell().Text("Valor C$"); });
        foreach (var p in datos)
        {
            t.Cell().Text(p.Codigo); t.Cell().Text(p.Nombre); t.Cell().AlignRight().Text($"{p.ValorInventario:N2}");
        }
    });
    page.Footer().AlignCenter().Text(x => { x.Span("Página "); x.CurrentPageNumber(); });
})).GeneratePdf(ruta);

Buenas prácticas: generar el reporte con Task.Run para no congelar la interfaz (Unidad III), pedir la ruta con SaveFileDialog (Unidad I), usar fórmulas en Excel en lugar de valores calculados, y ofrecer abrir el archivo al terminar.

Unidad V · 5. Servicios web y HTTP

Un servicio web es una aplicación que ofrece datos o funciones a otras aplicaciones a través de la red usando el protocolo HTTP. En el estilo REST, cada recurso tiene una URL y se opera con métodos HTTP; las respuestas suelen venir en JSON (y en servicios más antiguos, en XML).

ElementoEjemplo
MétodoGET (leer), POST (crear), PUT (reemplazar), DELETE (eliminar)
URLhttps://open.er-api.com/v6/latest/USD
Código de estado200 OK · 404 No encontrado · 429 Demasiadas solicitudes · 500 Error del servidor
EncabezadosAccept: application/json · Authorization (si requiere clave)
Cuerpo (JSON){ "result": "success", "base_code": "USD", "rates": { "NIO": 36.62 } }
Unidad V · 6. Clases para el consumo de servicios web
ClaseFunción
HttpClientEnvía peticiones HTTP y recibe respuestas. Se crea una sola instancia para toda la aplicación.
HttpResponseMessageRespuesta: StatusCode, encabezados y contenido; EnsureSuccessStatusCode() lanza error si no es 2xx.
System.Text.Json / ReadFromJsonAsync<T>Convierte JSON en objetos C# (deserialización).
[JsonPropertyName]Relaciona el nombre del campo JSON con la propiedad C#.

C#
private static readonly HttpClient http = new() { Timeout = TimeSpan.FromSeconds(10) };

public async Task<(decimal Nio, string Fuente)> ObtenerNioPorUsdAsync()
{
    try
    {
        using var resp = await http.GetAsync("https://open.er-api.com/v6/latest/USD");
        resp.EnsureSuccessStatusCode();
        var datos = await resp.Content.ReadFromJsonAsync<RespuestaTipoCambio>();
        return (datos!.Tasas["NIO"], "open.er-api.com");
    }
    catch (Exception ex) when (ex is HttpRequestException or TaskCanceledException)
    {
        // Sin Internet: usar el respaldo local
        var local = JsonSerializer.Deserialize<RespuestaTipoCambio>(File.ReadAllText("tipo_cambio_offline.json"))!;
        return (local.Tasas["NIO"], "respaldo local");
    }
}
C#
// XML: <tasas base="USD"><tasa moneda="NIO">36.62</tasa></tasas>
var doc = XDocument.Parse(xml);
var nio = decimal.Parse(doc.Root!.Elements("tasa")
            .First(e => (string?)e.Attribute("moneda") == "NIO").Value,
            CultureInfo.InvariantCulture);

La llamada es asíncrona (await): mientras llega la respuesta, la interfaz sigue respondiendo. Siempre se deben prever tres fallos: sin conexión (HttpRequestException), tiempo agotado (TaskCanceledException) y respuesta inesperada (JsonException o datos faltantes).

Unidad V · 7. Estudio de caso: tipo de cambio para valorar el inventario

El inventario se valora en córdobas; la cooperativa necesita el equivalente en dólares. AgroStock consulta un servicio público y gratuito de tipos de cambio, muestra la tasa y su fuente en la barra de estado, y la incluye en el reporte PDF. En zonas con Internet intermitente, la aplicación usa un respaldo local y lo indica claramente.

  • Analiza la API antes de usarla: documentación, límites de uso, licencia y atribución requerida.
  • El tipo de cambio oficial de Nicaragua lo publica el Banco Central de Nicaragua (BCN); investiga si ofrece un servicio consultable y compáralo con el servicio usado en clase.
  • Otros casos posibles: consultar el clima para planificar la aplicación de fertilizantes, o códigos postales/municipios desde un servicio público.

Práctica: ejercitación y retos
Consultas LINQ (individual). Escribe con EF Core la consulta que:


  1. Devuelva los productos de la categoría «Semillas» ordenados por nombre.
  2. Cuente los productos con existencia menor que 10.
  3. Obtenga el producto de mayor precio (OrderByDescending + FirstOrDefault).
  4. Calcule el valor total del inventario.
  5. Agrupe por categoría y devuelva cantidad de productos y valor (GroupBy).


Retos


  1. Nivel 1: agrega al PDF un resumen por categoría usando ProductoService.ResumenPorCategoria().

Síntesis
  • Un ORM mapea clases a tablas: se trabaja con objetos y LINQ, y SaveChanges genera el SQL.
  • Un reporte útil tiene encabezado, detalle, totales y pie; se genera sin congelar la interfaz.

  • AgroStock integra las cinco unidades: GUI, base de datos, concurrencia, ORM/reportes y servicios web.
